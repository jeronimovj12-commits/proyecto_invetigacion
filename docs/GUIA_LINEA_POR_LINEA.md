# Guía línea por línea del proyecto

Cada línea funcional está comentada en el archivo fuente cuando el formato lo permite. Este índice organiza los archivos propios por carpeta y relaciona las líneas físicas no vacías para facilitar la sustentación.

## Alcance y exclusiones

Incluye código de aplicación, pruebas, scripts, SQL, plantillas, estilos, configuración de ejecución y contenedores: Python, SQL, PowerShell, YAML, CSS, HTML/Jinja, JSON, requisitos no bloqueados y Dockerfiles.

Se excluyen líneas en blanco, `.lock`, documentos Markdown, binarios, imágenes, PDF, DOCX, XLSX, modelos gráficos, cachés, dependencias copiadas, entornos virtuales, `.git`, el SQL fuente del curso en `ProyectosDeAula/db_scripts/postgresql/` y los tres archivos reservados (`prueba_permisos_v3_equipo.py`, `VERIFICACION_API_V3_EQUIPO.md`, `VERIFICACION_FRONT_V3_EQUIPO.md`). El JSON de Postman se lista pero no recibe comentarios, porque JSON no admite comentarios válidos.
